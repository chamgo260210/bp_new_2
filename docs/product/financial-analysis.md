# 재무·수익성 분석

재무·수익성 분석은 완료된 사업 타당성 분석과 확정 구조화 계획을 근거로, 사용자가 확인한 가격·판매량·비용 가정을 계산하는 독립 기능이다. 사업 타당성 분석의 정성 평가를 대체하거나 확장하지 않는다.

- 지원 수익 모델: 일회성 판매, 구독, 혼합
- 분석 기간: 12·24·36개월
- 시나리오: 보수, 기준, 낙관
- 결과: 월별 매출·변동비·고정비·영업손익·누적 현금흐름, 손익분기, 투자 회수, 필요 운영자금, 단일 변수 민감도
- 데이터 보존: 완료 분석은 당시의 계획·사업성 분석·사용자 입력 Snapshot을 유지하며 원본 변경으로 자동 갱신되지 않는다.

이 결과는 입력 가정에 따른 예상값이며 실제 매출·비용·투자 성과를 보장하지 않는다. 회계·세무·투자 자문을 대체하지 않는다.
