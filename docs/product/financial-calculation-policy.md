# 재무 계산 정책

모든 금액 계산은 `BigDecimal`, 원 단위 `HALF_UP` 반올림을 사용한다. 무작위 값과 외부 AI 예측은 사용하지 않는다.

- 매출 = 가격 × 판매량
- 변동비 = 단위 변동비 × 판매량 + 매출 × 결제 수수료율 + 기타 단위 변동비 × 판매량
- 공헌이익 = 매출 - 변동비
- 영업손익 = 공헌이익 - 월 고정비
- 누적 현금흐름 = 초기 투자비의 음수 + 월별 영업손익 누계
- 손익분기 판매량 = 월 고정비 ÷ 공헌이익 단가

구독형은 월초 고객, 신규 고객, 이탈 고객, 평균 활성 고객을 기준으로 월 구독 매출을 산출한다. 공헌이익 단가가 0 이하이면 손익분기점은 제공하지 않고 계산 불가 사유를 표시한다. 필수 가격·판매량 값이 누락됐을 때 0으로 대신 계산하지 않는다.
