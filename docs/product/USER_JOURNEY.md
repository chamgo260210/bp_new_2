# Target User Journey

- Status: TARGET_CANONICAL
- Last Reviewed Commit: e16bd316ac881f4c5fab076e65c14657f6a8c7d4
- Scope: End-to-end user journey
- Supersedes: Legacy validation and marketing flow documents
- Implementation Status: NOT_STARTED

1. 사용자는 Project를 만들고 텍스트, 파일 또는 질문 응답으로 IdeaSource를 추가한다.
2. 시스템이 입력을 정규화하며 사용자는 정규화된 아이디어와 출처를 확인한다.
3. 한국 법률 근거를 이용한 검토 결과와 주의사항을 확인한다.
4. Concept Builder가 복수 후보를 만들고 Quick Assessment 결과를 제공한다.
5. 사용자는 shortlist를 검토하고 상세 분석 대상을 확정한다.
6. 시장, BM, 기술·운영, 재무 관점의 상세 분석과 근거를 비교한다.
7. AI 권고와 별개로 사용자가 최종 concept를 선택한다.
8. 선택 concept에 대한 Three-Layer Persona Card를 검토한다.
9. Persona별 독립 인터뷰 결과를 검토한다. Persona끼리는 대화하지 않는다.
10. Marketing Workspace에서 시안을 생성·편집·관리한다.
11. Persona 관점으로 시안 A/B를 상대 비교한다. 실제 전환 실험으로 표현하지 않는다.
12. 사용자는 versioned Final Report를 생성하고 현재·이전 snapshot을 조회하거나 export한다.

각 단계는 입력 provenance, TaskRun 상태, AI 결과, 사용자 결정을 구분해 보여야 한다.
