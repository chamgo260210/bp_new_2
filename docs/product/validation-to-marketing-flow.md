# 검증 결과에서 마케팅 콘텐츠로 이어지는 흐름

## 데이터 흐름

1. 완료된 패널 인터뷰는 `panelInterviewId`와 대상 Persona ID를 시장 반응 작성 화면에 전달한다.
2. 완료된 패널 또는 시장 반응 결과는 Marketing 신규 작성 Route에 결과 ID를 전달한다.
3. Marketing 서버는 프로젝트 소유권, 미삭제 상태, `COMPLETED` 상태를 검증한다.
4. `MarketingSourceSnapshotService`가 프로젝트, Persona, 법률·사업성, 인터뷰·시장 반응의
   안전한 요약과 사용자 입력을 하나의 Snapshot으로 저장한다.

다른 프로젝트, 삭제되었거나 미완료인 결과는 거부한다. 시장 반응이 완료 인터뷰를 참조하고
사용자가 패널 ID를 별도로 지정하지 않았다면 연결된 인터뷰 Summary도 반영할 수 있다.

## Snapshot 불변성과 명시적 갱신

기존 콘텐츠를 편집해도 Source Snapshot은 자동으로 바뀌지 않는다. 사용자가 Workspace의
`검증 결과 다시 불러오기`를 실행할 때만 Snapshot 버전이 증가한다.

- Source만 갱신: 현재 카피와 현재 버전을 유지한다.
- Source 갱신 후 새 초안: 기존 카피를 보존하고 새 버전을 생성한다.

감사 이벤트에는 패널 ID, 시장 반응 ID, Snapshot 버전만 기록한다. 전체 Snapshot과 질문·답변,
점수 Matrix는 감사 로그에 기록하지 않는다.

## 카피와 Preset 규칙

- Headline: 시장 반응의 우수 메시지, 인터뷰의 반응 좋은 메시지 순서로 우선한다.
- Body: 공통 요구, 구매 동기, 공통 긍정 요인을 조합한다.
- CTA: 시장 반응 추천 CTA가 있으면 목적 기본 CTA보다 우선한다.
- 검토: 거부 요인, 부정 요인, 피해야 할 표현, 법률 요약을 편집자 안내로 제공한다.
- Preset: 근거·신뢰 보완은 신뢰형, 행동 신호는 활력형, 간편·명확성 요구는 미니멀형을 우선한다.

현재 실제 LLM과 이미지 생성 AI는 연결하지 않는다. 카피와 Preset은 같은 입력에 같은 방향을
제공하는 규칙 기반 추천이며 실제 광고 성과를 보장하지 않는다.

## 내보내기 한계

PNG는 Client Canvas에서 생성되며 서버 감사 대상이 아니다. 실제 Pixel과 Preview는 같은
Renderer를 사용한다. 폰트 로딩과 텍스트 Overflow 검사를 통과하지 못하면 다운로드를 시작하지
않는다. JPEG, PDF, 외부 이미지 URL과 생성형 이미지는 현재 범위가 아니다.
