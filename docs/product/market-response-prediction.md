# 검증 데이터 기반 예상 시장 반응

## 성격

시장 반응 점수는 실제 시장조사, 실제 전환율 또는 구매 확률이 아니다. 동일 Persona와 메시지를
같은 규칙으로 비교하기 위한 상대 지표다. UI는 숫자와 함께 낮음·보통·높음·매우 높음 Label을
항상 표시한다.

## 입력

- 현재 관리자 허용 목록의 Persona 1~3개
- 비교 메시지 1~3개, 메시지별 300자 이하
- 선택적인 가격대·가격 인식과 주요 채널
- 선택적인 완료된 예상 인터뷰 결과
- 프로젝트, Persona, 사업성·법률 검토의 안전한 요약

패널 인터뷰가 없어도 실행할 수 있다.

## 결정론적 점수 규칙

`MarketResponseScoringService`는 무작위 값을 사용하지 않는다. Persona Code, 메시지, 지표 Key의
안정적인 Hash를 기본값으로 사용하고 다음 요소를 제한적으로 보정한다.

- Persona 핵심 특성과 메시지 문자열의 일치
- 완료된 패널 인터뷰 연결 여부
- 가격 정보 존재 여부
- 메시지의 근거·사례·숫자 포함 여부
- 메시지 길이와 채널 맥락

결과는 20~95 범위로 제한한다. 지표는 관심도, 이해도, 신뢰도, 사용 의향, 구매·신청 의향,
공유·추천 의향이다. 같은 입력은 같은 점수를 만든다.

각 Persona·메시지 조합에 긍정 요인, 부정 요인, 개선 제안을 제공한다. Summary는 가장 반응이
좋은 Persona와 메시지, 공통 요인, 추천 CTA·채널, 가격 우려를 별도 필드로 저장한다.

## 저장·정책

`market_response_predictions`에 입력, 결과, Summary, Source Snapshot과 선택적
`panel_interview_id`를 저장한다. 쓰기는 프로젝트 소유권과 유지보수 정책을 적용하고 조회는
유지보수 중에도 허용한다. 삭제는 Soft Delete다.

마케팅 콘텐츠 신규 작성 Route에는 `marketResponseId`와 연결된 `panelInterviewId`를 함께
전달한다. Marketing Snapshot에는 전체 점수 Matrix 대신 우수 Persona·메시지, 추천 CTA·채널,
공통 긍정/부정 요인과 개선 제안만 저장된다.
